# Wood Box Cost Calculator

React/Vite calculator for estimating pine wood packing box costs with CFT-based pricing.

## Features

- Box dimension presets and live inch-to-mm conversion
- Editable parts/CFT table
- Configurable wood, labour, transport, packing, clamp, waste, and profit values
- Detailed internal quote printout
- Client-facing quote printout with optional extra sections
- Light and dark UI modes

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
